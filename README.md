# CILPA Cloudflare Site v11

Versi ini fokus ke landing page interaktif.

## File penting
- `index.html`
- `assets/css/style.css`
- `assets/css/tailwind-lite.css`
- `assets/css/motion-v11.css`
- `assets/js/main.js`
- `assets/js/three-bg.js`

## Video header
Masukkan video ke:

`assets/videos/cilpa.mp4`

Video header di landing page memakai rasio 16:9, autoplay, muted, loop, dan playsinline.

## Fitur interaktif landing page
- Custom cursor desktop
- Three.js animated background
- Cursor spotlight/aurora background
- Scroll-driven parallax
- Hero text rotator
- Running text/marquee
- Magnetic buttons
- Tilt hover cards
- Reveal-on-scroll
- WhatsApp inquiry form

## Deploy Cloudflare Pages
Upload isi folder ini ke Cloudflare Pages. Build command dikosongkan, output directory `/`.
